## 3. 后续 Agent 开发铁律 (严格执行 `AGENTS.md`)

1. **绝对禁止代码注释**：零注释原则（无解释性注释、无 docblock、无 TODO/FIXME、无 lint/type 抑制指令、无废弃代码）。依靠语义化命名、架构与测试自解释。
2. **禁止 AI 署名**：Commit 信息与 PR 中绝对不可包含 `Co-authored-by: Claude/Codex/AI` 或 `Generated with...` 等 AI 标记。
3. **改一处修全局**：修改公共模式时，必须 grep 全仓（`src/`, `plugins/`, `test/`, `scripts/`）将同类模式一次性修复，根绝残留隐患。
4. **状态落地 Postgres**：核心业务状态（Audit、Logs、队列、配置）严禁驻留单机内存 Map，必须落地持久化数据库。
5. **单 Gate 闭环**：每个 Gate 完成后必须跑通指定测试，在 `plan.md` 记录验收结果并打上对应的 `gate/gXX-pass` 标签。
